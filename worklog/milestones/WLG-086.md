# WLG-086 — 재계획 결함 근거와 재작업 종류 저장 (ADR-0074)

2026-11-14, Codex. 브랜치 `feature/plan-evidence-and-rework-kind`. ADR-0072의 후속 차수다.

## 범위와 결정

- [ADR-0074](../../sdd/architecture/decisions/ADR-0074.md)에 변경 없음 차단 뒤 같은 파일을 다시 수정하는 계획의 근거 검사와 재작업 회차 저장을 결정했다.
- PM 계획의 파일별 `defectEvidence`는 현재 파일의 정확한 인용문 또는 저장된 실패 QA 기준을 가리킨다. 엔진이 계획 승인 전에 파일 범위와 근거를 다시 확인한다. 근거는 쓰기 승인이나 완료 판정이 아니다.
- 새 업무는 `repairRound` 저장 필드로 재작업 여부를 판단한다. 필드가 없는 기존 업무만 역사적 제목 접두어를 읽는다.

## 구현

- 재계획 검증은 변경 없음으로 차단된 원래 업무와 새 계획의 중복 파일을 대조한다. 필요한 파일별 근거가 없거나 현재 내용·저장된 QA 판정과 일치하지 않으면 PM에게 계획 수정을 요청한다.
- 업무 생성, 권한 범위, QA 목표, 팀원 문맥과 화면의 재작업 표시에 저장된 회차를 사용한다. 새 일반 업무의 제목이 재작업 접두어처럼 보여도 권한이 바뀌지 않는다.
- DM-03·DM-04, 복구 사용자 흐름, 검증 기준을 갱신했다.

## 검증

- `cargo check --locked --lib` 통과.
- `cargo test --locked --lib --no-run` 통과.
- Vitest 161개 통과.
- 전체 Rust 시험 첫 실행은 256 통과·1 실패·3 무시였다. 실패한 기존 종단 시험은 새 재작업 제목 저장 방식 때문에 모의 AI 요청문에서 재작업 회차가 빠진 문제를 드러냈다. 저장된 회차를 요청문 표시로 복원했고, 같은 재작업 경로의 집중 시험 2개가 재실행에서 통과했다. 수정 뒤 전체 시험은 재실행하지 않았다.
- `npm run build:v4` 통과. Vite의 기존 500 kB 청크 크기 경고는 남는다.
- `cargo clippy --locked --lib -- -D warnings` 통과.
