# CLI 에이전트 호출·토큰 분석 자료 (2026-10-21, Codex)


- [x] 기본 앱 SQLite의 동일 수용 기준인 레벨 4·5 Dev1(Codex) / Dev2(Claude) 업무 2쌍을 대조했다. 각 쌍은 `dev1`/`dev2` 부분을 제외한 선언 파일 구성이 같고, 저장된 수용 기준도 같다.
- [x] 호출 경로를 `engine.rs` → `provider.rs` → `runtime.rs`에서 확인하고, 앱 호출별 사용량·작업 이벤트·QA 판정과 해당 로컬 CLI 세션의 캐시/내부 응답·도구 이벤트를 대조해 [인터랙티브 분석 HTML](../../analysis/cli-agent-token-analysis.html)을 작성했다. 요청문·파일 본문·자격 증명은 자료에 넣지 않았다.
- [x] HTML의 JavaScript 문법 검사 통과. 레벨 선택과 호출 단계 선택은 정적 데이터를 갱신한다. 실제 브라우저 화면 검사는 헤드리스 캡처가 결과 파일을 만들지 못했고, 앱 브라우저의 로컬 `file:` 페이지 관찰이 URL 정책으로 거부돼 완료하지 못했다. 거부 뒤 우회하지 않았다.
- 한계: Codex/Claude의 로컬 내부 이벤트 단위는 완전히 동일하지 않다. 입력 총량 차이를 내부 응답 수와 평균 입력 크기로 분해할 수 있지만, 모델 자체의 인과적 효율 차이는 이 두 쌍만으로 입증할 수 없다. HTML은 앱 동작을 변경하지 않는다.
