# WLG-083 — 볼트 미완료 과제 확인과 Windows 빌드 검증

2026-11-10, Codex. 볼트 프로젝트 페이지의 `AI에게 맡길 과제` 5건을 현재 저장소와 대조하고 실행 가능한 검증을 수행했다. 볼트 파일은 수정하지 않았다.

## 항목별 결과

1. **Self grill E21 기록 정정:** 이미 완료. [WLG-074](WLG-074.md)는 [WLG-061](WLG-061.md)에 현재 전송 미리보기·승인 경로를 날짜 붙여 정정한 사실을 확인했다. 실제 전송 내용·목적지·호출 수의 데스크톱 QA는 별도 열린 검증이다.
2. **실제 제3자 외부 어댑터로 ADR-0070 확인:** 미완료. 이번 세션에서 사용자가 실행 가능한 제3자 어댑터가 없다고 확인했다. 기존 모의 AI·합성 프로세스 시험은 제3자 실연동을 대신하지 않는다. 실행 파일·인자·기능 선언이 준비되면 격리된 시험 목표에서 이벤트, 취소와 재개 선언을 확인한다.
3. **Windows 설치 파일 빌드:** `scripts/build-installer-windows.ps1 -CheckOnly`와 실제 실행이 모두 종료 코드 0. 프런트 타입 검사·v4 빌드, Rust 릴리스 빌드와 NSIS 패키징이 성공했다. 산출물 `src-tauri/target/release/bundle/nsis/AI Organization OS_0.1.0_x64-setup.exe`는 6,722,133바이트, SHA-256 `55602019E9EFE231594E2C76096DE54E8CE74D9EDB938B72A2FCF52540B63A4D`. 설치 파일을 실제 설치해 실행하는 QA는 수행하지 않았다.
4. **기본 경로의 잠긴 실행 파일 재빌드:** 원래 체크아웃 `src-tauri`의 `cargo build --locked`가 종료 코드 0으로 완료됐다. 앞서 발생한 `LNK1104`는 재현되지 않았다.
5. **기본 경로의 개발 앱·용량 게이트:** 같은 경로에서 `cargo build --locked` → `cargo test --locked -- --test-threads=1` → `cargo build --locked` → 입력 무변경 재빌드를 완료했다. Rust 시험은 255개 통과·0개 실패·3개 무시. `target/debug`는 첫 빌드 뒤 3.81 GiB, 시험 뒤 4.06 GiB, 후속 빌드와 무변경 재빌드 뒤 각각 4.05 GiB였다. 최종 5 GiB 이하, 무변경 증가 측정상 0 GiB로 용량 기준을 통과했다. 앞선 [WLG-081](WLG-081.md)의 소스 줄 번호 확인도 유지된다. `npm run tauri:v4`는 Vite 서버와 `target/debug/ai-organization-os.exe`를 시작했고 `AI Organization OS` Windows 창을 확인했다. 확인 후 개발 앱을 종료했으며 종료 뒤 용량도 4.05 GiB였다.

## 남은 범위

- 실제 제3자 어댑터가 준비되면 ADR-0070 실연동을 검증한다.
- NSIS 설치 파일의 설치·실행, 실제 제공자 호출을 사용하는 앱 시나리오는 이 빌드·시작 확인의 범위 밖이다.
- `npm ci`를 별도 작업 트리에서 시도했으나 샌드박스 DNS `ENOTFOUND`로 중단됐다. 실제 설치·개발 앱 검증에는 의존성이 이미 설치된 원래 체크아웃을 사용했다.
