# WLG-069 — 열린 작업의 현재 프로젝트 기본 범위

2026-11-08, Codex. 사용자 요청: `열린 작업`은 선택된 프로젝트만 기본으로 보여 주고, 펼친 창에서 `닫기` 왼쪽의 `모든 작업 보기` 버튼으로 다른 프로젝트의 작업을 확인한다.

## 범위

- GC-05, UF-08, Validation 및 QA-30에 현재 프로젝트 기본 범위와 전체 보기 전환을 명시했다.
- 세 앱 셸이 선택된 프로젝트 ID를 공통 `OpenWorkLauncher`에 전달한다. 배지 숫자와 기본 목록은 해당 프로젝트의 미완료 목표만 사용한다.
- 펼친 창에 전체 보기 토글을 추가했다. 닫기, Escape, 업무 선택, 프로젝트 변경 시 기본 범위로 돌아간다. 다른 프로젝트 업무를 선택하면 해당 프로젝트로 전환하는 기존 경로를 유지한다.
- 범위를 전환할 때 목록의 다섯 항목 펼침 상태도 초기화한다.

## 검증·한계

- `npx vitest run src/openWork.test.ts src/OpenWorkLauncher.test.ts`, `npm run build:v3`, TypeScript 타입 검사(root, v2, v4) 통과.
- QA-30의 실제 데스크톱 조작과 화면 배치는 아직 수동 확인하지 않았다.
