# WLG-078 — clippy 경고 0개와 불안정한 종단 시험 정리

2026-11-10, Claude. [WLG-077](WLG-077.md) 다음의 작은 정리. 이 PC에 clippy를 설치하고(`rustup component add clippy`) 처음으로 돌렸다.

## 변경

- `cargo clippy --all-targets` 경고 26개 → 0개.
  - 자동 수정: 슬라이스 복제(`std::slice::from_ref`), `map_or(true, …)`→`is_none_or`, 불필요한 `return`·`format!`·`map`, `last()`→`next_back()`, 대소문자 무시 비교, `match` 가드
  - 직접 수정: 중첩 `format!`→`format_args!`, 한 줄의 두 `if`를 줄로 나눔(의도한 순차 실행이며 결함 아님), 쓸모없는 struct update 제거
  - 시험에서만 쓰는 `verify_task_reuse`는 `#[cfg(test)]`로 묶어 "사용되지 않는 함수" 경고를 없앰
  - 그대로 둔 것(이유를 적은 국소 `allow`): SQLite 행을 바로 받는 튜플 4곳(`type_complexity`), CEO 커밋 양식 필드를 받는 Tauri 명령(`too_many_arguments`)
- 반복 실행에서 두 종단 시험이 가끔 실패했다(`resume_closes_a_conversation…`, `a_denied_scope_addition_blocks…`). 엔진은 상태를 바꾼 직후 대화 기록·차단 기록을 저장하는데, 시험은 상태만 기다리고 기록을 바로 읽었다. 기록이 생길 때까지 기다리는 `eventually` 도우미를 추가했다.

## 검증·한계

- `cargo clippy --all-targets`: 경고·오류 0.
- `cargo test`: 수정 후 세 번 연속 238 통과·0 실패·3 무시. 수정 전에는 일곱 번 중 두 번 각각 다른 시험 하나가 실패했다.
- 다른 시험에도 같은 종류의 경합이 남아 있을 수 있다. 반복 실행에서 다시 보이면 같은 방식으로 고친다.
