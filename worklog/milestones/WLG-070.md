# WLG-070 — 필요한 명령만 승인 요청

2026-11-08, Codex. 사용자 제보: Claude Developer의 승인 카드에 `grep`, `head`, `node` 확인 명령과 heredoc 안의 JavaScript·PowerShell 코드 조각까지 나열됐다.

## 범위

- [ADR-0067](../../sdd/architecture/decisions/ADR-0067.md)을 추가하고 Security, AI-03, UF-05, Validation, QA-56을 갱신했다.
- PM이 `request_approval`을 고르면 거절 호출에서 앱이 추출한 후보 명령 규칙 중 필요한 키만 제출한다. 앱은 실제 후보 키만 허용하고, 한 호출 안에 여러 명령이 있어도 그 부분집합으로 CEO 카드를 만든다. 선택이 없거나 응답이 잘못되면 기존 권한 내 재시도를 제한 횟수까지 진행하고 거절 전체를 카드로 보내지 않는다.
- 여러 줄 셸 입력, heredoc, 단일 줄 제어문과 인라인 Node 스크립트는 줄별 명령 규칙으로 만들지 않는다. 모의 AI에 불필요한 스크립트 거절을 더하는 시나리오와 회귀 시험을 추가했다.

## 검증·한계

- `cargo check --locked --tests`, `node --check scripts/mock-ai/mock-adapter.mjs`, `git -c core.whitespace=cr-at-eol diff --check` 통과.
- Windows Rust 시험 실행 파일은 기존과 같이 `0xc0000139 STATUS_ENTRYPOINT_NOT_FOUND`로 시작되지 않아 새 단위·종단 시험은 실행되지 않았다. 실제 Claude 세션의 카드 축소는 미검증이다.
- PM이 필요한 호출을 잘못 고르면 해당 명령은 자동 승인되지 않는다. QA가 현재 산출물을 실패로 판정할 수 있으며, 다음 계획·복구 흐름이 이를 다룬다.
