# WLG-080 — v4 Tauri 실행의 Rust 증분 캐시 정리

2026-11-10, Codex. 사용자 요청: `npm run tauri:v4` 빌드 흐름에서 오래된 Rust 증분 캐시를 자동 정리한다. 직접 실행하는 `cargo test`는 범위에서 제외한다.

## 범위와 결정

- `package.json`의 `pretauri:v4`·`posttauri:v4` 및 `pretauri:v4:build`·`posttauri:v4:build`에 로컬 정리 스크립트를 연결했다.
- 대상은 `src-tauri/target/debug/incremental`로 제한했다. 4 GiB 초과 시 7일 이상 된 해시 폴더부터 지우며, 크레이트마다 최근 두 폴더를 보존한다. `cargo`·`rustc` 실행 중에는 건너뛰고, 정리 오류는 빌드를 막지 않는다.
- `sdd/workflow.md`와 `v4/README.md`에 범위와 동작을 기록했다. 제품 동작이나 승인 규칙은 바꾸지 않았다.

## 검증과 남은 범위

- `node --test scripts/clean-rust-incremental.test.mjs`: 2개 통과(오래된 폴더만 삭제, Cargo 실행 중 건너뛰기).
- `npm run pretauri:v4`: 실제 캐시의 오래된 폴더 43개를 정리해 2.27 GiB 확보. 정리 전 6.13 GiB, 후 3.86 GiB.
- `npm run posttauri:v4:build`: 4 GiB 미만에서 종료 코드 0, 추가 삭제 없음. `git diff --check` 통과.
- 전체 Tauri 앱 빌드·실행은 이 정리 작업의 검증 범위에 넣지 않았다. `npm run tauri:v4` 종료 시 npm의 post 단계가 실행되는지는 실행 종료 방식에 따라 확인이 필요하다. 다음 시작의 pre 단계는 별도로 작동한다.
- `cargo test` 직접 호출과 `npm run tauri -- dev` 같은 다른 진입점에는 정리가 연결되지 않는다.
