# WLG-087 — 볼트 과제 안내 라운드 2

2026-11-14, Codex. 브랜치 `docs/vault-round2-guidance`.

## 범위

- 볼트의 라운드 2 과제를 사용자가 직접 지정했다. 저장소 `AGENTS.md`와 `CLAUDE.md`의 기존 전체 AI 과제 조회 안내를 실행 도구별 조회로 갱신했다.
- MCP `vault_list_tasks`의 `agent` 값(`claude`, `codex`, `ucompany`)과 Python 대체 명령의 `--agent`를 명시했다. 다른 담당 과제는 사용자가 직접 지정한 경우에만 진행한다.
- 볼트 과제는 저장소와 대조할 자료로 취급하고, 사용자 선택 뒤 시작한다. 완료한 과제 원문과 결과를 세션 요약에 적고 MCP 제출과 처리 요청으로 넘긴다. 세부 계약은 볼트의 `mcp/USAGE_PROMPT.md` 한 경로로 연결했다.

## 확인

- 볼트 MCP 계약 v1.1.0의 `vault_list_tasks`, `vault_submit_summary`, `vault_request_ingest`와 `scripts/ai-tasks.py --agent` 지원을 확인했다.
- 문서 변경만 있으므로 제품 빌드와 시험은 실행하지 않았다. `git diff --check`와 변경 파일 범위를 확인한다.

## 남은 위험과 다음 행동

- 현재 Codex 환경에는 볼트 MCP 도구가 노출되지 않고 `python` 명령도 PATH에 없다. 이번 세션의 `/vault-log`는 사용자가 요청한 스킬 절차로 inbox에 제출한다. MCP 연결은 별도 환경 설정이 필요하다.
- PR은 저장소 절차에 따라 준비한다. 실제 MCP 연결과 사서 처리 종단 동작은 이 문서 변경만으로 검증되지 않는다.
