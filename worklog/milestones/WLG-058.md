# 작업 차수 경계 구조화 요약과 미완료 기록 점검 (2026-10-25, Codex)

- 범위: CEO가 선택한 ‘작업 차수 경계에서 구조화 요약’을 ADR-0056, GC-01/02, DM-02, Security, 수용 기준과 QA-51에 반영했다. 후속 작업과 수동 목표 버전 생성이 공통 저장소 경로에서 인계를 만든다.
- 구현: `goal_context.rs`가 저장된 첫 CEO 목표, 이전 CEO 지침, 직전 차수 상태·작업 파일·결과 일부, 최신 지침 원문을 한도 안에서 조합한다. 누적 대화 텍스트를 4자당 1토큰으로 추정하여 약 8,000토큰 이상이면 직전 채팅 발췌를 제외한다. 이전에 생성한 긴 목표 내용을 다음 목표에 재귀적으로 붙이지 않는다. 원문 기록과 차수별 승인·QA는 유지한다.
- 검증: `cargo check --locked --all-targets`, `npm run build:v3`, `npx vitest run src/goalChain.test.ts`(5개 통과), `git -c core.whitespace=cr-at-eol diff --check` 통과. 요약 함수만 임시 독립 Rust 실행 파일로 빌드해 32,000자 대화에서 8,000토큰 경계·발췌 제외·최신 지침 보존·12,000자 한도를 확인했고 임시 파일은 제거했다. 긴 대화와 세 번째 차수의 인계·기존 승인 보존을 확인하는 저장소 Rust 단위 시험은 추가·컴파일했으나, Windows 시험 바이너리가 `STATUS_ENTRYPOINT_NOT_FOUND`로 시작하지 않아 시험 통과 여부는 확인하지 못했다. PATH에서 Poppler를 빼고 시스템 경로만 써도 동일했다.
- 워크로그 점검: [WLG-001](WLG-001.md)의 구조화 요약 미구현 항목은 이번 변경으로 구현 단계까지 진행했다. 완료→후속 지시→새 승인→작업→QA의 실제 AI·화면 종단 검증은 여전히 열려 있다. [v3 파일럿 미검증 범위](../programs/v3-first-package/open-verification.md)의 QA-36/37/38/39는 이번 구현과 별도 실앱·제공자 검증으로 남는다. [M5](../programs/v3-first-package/M5.md)의 남은 자산 항목은 후속 M7에서 해소돼 인덱스 상태를 수정했다. 현재 확인된 나머지 열린 검증·기반 작업을 [인덱스](../00_index.md#확인된-열린-작업)에 연결했다.
- 다음: Rust 시험 실행 파일의 Windows 로더 오류를 해결한 뒤 해당 단위 시험을 실행하고 QA-51 및 완료 후 후속 작업의 실제 화면·모의 AI 종단 흐름을 수행한다. 실앱과 실제 제공자 검증은 통과 근거가 생길 때만 체크한다.
