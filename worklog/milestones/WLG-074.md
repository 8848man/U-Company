# WLG-074 — ADR 색인 순서·날짜 형식과 Self grill 기록 정정

2026-11-10, Claude. CEO가 남은 과제 목록에서 CLI로 할 수 있는 일을 바로 진행하라고 요청했다.

## 변경

- **ADR 색인:** 표 위에 떨어져 있던 ADR-0062·0068 행과 순서가 뒤섞인 행(0064, 0047~0067)을 번호순 68행으로 정리했다. 색인 머리에 행 순서와 ADR 머리 형식(`Status:` 다음 `Date: YYYY-MM-DD`)을 적었다.
- **ADR 날짜:** `Date:` 줄이 없던 43개 ADR(0007~0015, 0033~0061, 0063~0067)에 `Status:` 괄호 안 날짜를 꺼내 `Date:` 줄을 더했다. `Status: Accepted 2026-10-02`처럼 괄호가 없던 0014·0015는 `Accepted (날짜)`로 맞췄다. 결정 내용은 바꾸지 않았다.
- **U16:** QA-39 열린 검증 안내와 워크로그 색인의 `v2/start-windows.ps1 … v3-pilot` 실행문을 `v4/start-windows.ps1 -DataDir .run-data\v4-pilot`로 정정했다([WLG-073](WLG-073.md)의 v4 기준).
- **E15:** [WLG-063](WLG-063.md)의 "`Snapshot`에 `reuseConflicts` 전달 필드가 없다"는 당시 문장은 보존하고, 현재 `storage.rs::snapshot`→`Snapshot.reuse_conflicts`→`v3/src/App.tsx`의 `ReuseConflictPanel`로 이어지는 정적 연결과 화면 미검증을 구분하는 날짜 붙은 정정을 덧붙였다.
- **E21:** [WLG-061](WLG-061.md)의 2026-10-31 검증 기록 정정 절이 이미 옛 `ask_goal` 설명을 과거 기록으로 표시하고 현재 `preview_tech_preset_ai_draft`→승인/거절 경로를 적고 있어 추가 정정하지 않았다. 실제 전송 내용·목적지·호출 수 검증은 데스크톱 QA로 남는다.
- **U17:** 이번에는 정정하지 않았다. 옛 대화 화면(`src/GoalConversationChat.tsx`)은 v1(`src/App.tsx`)과 v2에서만 쓰이고 "새 목표 열기"로 안내해 [UF-03](../../sdd/userFlow/UF-03-goal.md)의 "같은 대화에서 후속 작업"과 다르다. 고칠지 v1·v2를 정리할지는 CEO 결정(v1·v2 정리 시점)에 달려 있다.
