# WLG-076 — v1·v2 앱 정리, v4를 기본 앱으로

2026-11-10, Claude. CEO 결정: v1·v2를 정리한다. [ADR-0069](../../sdd/architecture/decisions/ADR-0069.md).

## 변경

- 삭제: 루트 `index.html`, `src/App.tsx`·`src/main.tsx`(v1), `src/GoalConversationChat.tsx`(v1·v2에서만 사용), `v2/`의 `App.tsx`·`main.tsx`·`V2Home.tsx`·실행 스크립트·Vite/TS 설정·README, `src-tauri/tauri.v2.conf.json`.
- 이동: v3 컨트롤러가 쓰는 `V2Navigation`·`V2Work`·`V2Connections`·`V2Projects`·`V2NotificationSettings`·`v2.css`를 `src/shell/`로(내용은 상대 경로만 바뀜). 진단 스크립트와 설치 파일 빌드 스크립트를 `scripts/`로.
- 기본 앱: `tauri.conf.json`이 `v4/dist`를 쓰고, `npm run dev`·`build`가 v4를 만든다. `scripts/start-windows.ps1`은 `v4/start-windows.ps1`로 넘긴다. `v4/start-ubuntu.sh`를 추가했다. 설치 파일은 `scripts/build-installer-windows.ps1` + `tauri.installer.conf.json`(NSIS만 켬).
- 문서: README, architecture, implementation-map, UF-03, UX 단순화 색인·UX-03, content-density, v3·v4 README, QA-36(옛 v2 README의 대화형 QA 순서를 옮김), ADR-0033·0039에 대체 표시.
- 남은 과제의 "v2/v3 컨트롤러 중복을 공용 훅으로"는 v2 컨트롤러가 사라져 필요 없어졌다. Self grill U17도 옛 대화 화면이 사라져 해소됐다.

## 검증·한계

- `tsc --noEmit`(루트·v3·v4) 통과, vitest 32파일 160개 통과, `npm run build`(v4) 통과, v3/v4 진입점에서 닿지 않는 소스 파일 없음(정적 import 추적).
- 바뀐 기본 설정으로 `npm run tauri dev`나 `scripts/start-windows.ps1`을 실제로 실행해 창을 띄우지 않았다. 설치 파일 빌드도 실행하지 않았다.
- 기존 v2 설치 앱(제품 이름 `Utopia Company v2`)이 있다면 새 설치 파일은 기본 제품 이름(`AI Organization OS`)으로 설치된다. 데이터는 `identifier`가 같아 공유된다고 보지만 실제로 확인하지 않았다.
