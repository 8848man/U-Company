# 한 목표 대화에서 반복 작업 (2026-10-25, Codex)


- [x] CEO 결정: 완료된 실행 목표의 기존 대화에서 후속 작업을 바로 지시한다. 내부적으로는 차수별 Goal ID를 유지하고, 이전 완료·QA·승인은 보존하며 다음 차수의 파일 쓰기는 새 계획 승인을 받는다. [ADR-0055](../../sdd/architecture/decisions/ADR-0055.md), GC-01/02/03, DM-02/04, UF-03, 목표 대화 수용 기준을 갱신했다.
- [x] 저장소에 완료 후 후속 작업 전용 전이를 추가했다. 기존 진행 중 방향 변경과 완료의 원자적 경주는 유지하고, 중복 후속 지시·중복 버전·보관한 목표를 거부한다. 미해결 지침이 있는 동안 보관을 막는다. 엔진은 대화 해석의 `followup`을 이 경로로 보내고, 완료 차수를 바꾸지 않은 채 다음 버전을 자동 계획한다.
- [x] v3 대화에서 완료 후 후속 작업 안내와 차수별 결과·QA 펼침을 제공한다. 새 버전은 기존과 같은 대화에 표시한다. 범위 승인 UI와 기존 v1/v2 화면은 이번 단위의 대상이 아니다.
- [x] 검증: `cargo check --locked --all-targets`, `npm run build:v3`, `npx vitest run src/goalChain.test.ts`, `git -c core.whitespace=cr-at-eol diff --check` 통과. 새 Rust 저장소 단위 시험은 컴파일됐지만 Windows 시험 실행 파일이 `STATUS_ENTRYPOINT_NOT_FOUND`로 시작하지 못해 결과 미확인. 실제 AI를 통한 후속 작업 종단 실행도 미확인.
- 다음: Windows 시험 실행 환경을 고친 뒤 완료 → 같은 대화 후속 지시 → 새 계획 승인 → 작업 → QA를 모의 AI와 실제 화면에서 검증한다. 현행 자동 버전 내용은 12,000자 상한이 있어 긴 연속 작업에는 한계가 있다. 긴 대화 문맥 요약의 임계값·보존 형식은 이번 요청에 세 안으로 제안하고, 선택 뒤 별도 명세·구현한다.
- 후속 기록(2026-10-25): 구조화 요약 선택과 구현·미검증 범위는 [WLG-058](WLG-058.md)에 기록했다. 위 `다음`은 이 마일스톤 당시의 재개 지점이다.
