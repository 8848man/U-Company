# M10 — 자료 끌어다 놓기와 상자 표시 (완료, 모의 렌더링 검증)


- [x] 원인: Tauri 2 창은 파일 끌어놓기를 기본으로 가로채(`dragDropEnabled: true`) Windows에서 화면의 HTML5 드롭이 동작하지 않는다(tauri-utils 설정 설명: "Disabling it is required to use HTML5 drag and drop on the frontend on Windows"). `tauri.conf.json` 창 설정에 `dragDropEnabled: false`. 네이티브 드롭을 쓰는 코드는 없다.
- [x] 화면: 새 목표 상자 위로 파일을 끌면 점선 안내("여기에 놓으면 자료로 첨부돼요")가 뜨고, 놓으면 첨부된다(자식 요소 위에서 깜빡이지 않게 깊이 계산). 첨부 자료는 Cowork처럼 상자로 보인다: 이미지는 변환된 WebP 미리보기, 글은 MD·TXT 표시, 이름·크기·상태, 글은 요구사항·참고 전환, 오른쪽 위 × 로 지우기. 준비 중인 파일은 자리표시 상자로 보인다.
- [x] 검증: 세 프런트 `tsc`, `vitest` 97, v3 빌드, `cargo check`. 모의 앱에서 PNG·md·txt 세 파일을 끌어 놓기 → 안내 표시, 자식 위 이동에도 유지, 놓은 뒤 사라짐, 상자 3개, × 로 1개 삭제, 콘솔 오류 0.
- 남은 위험: WebView2 실제 끌어놓기는 QA-47로 확인한다.
