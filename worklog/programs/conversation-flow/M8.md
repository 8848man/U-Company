# M8 — 참조 자료(긴 글·이미지)와 자료 정리 담당 (완료, 오프라인·모의 렌더링 검증)


- [x] 결정: CEO가 계획서의 권장안 전부와 자료 정리 담당(별도 역할, 제목 없는 긴 글·이미지만, 결과는 보여 주되 그대로 진행 가능)을 승인. [ADR-0049](../../../sdd/architecture/decisions/ADR-0049.md)(신규, 색인), [DM-06](../../../sdd/domain/DM-06-references.md)(신규, 색인), 보안 명세, GC-03, 구현 지도, QA-47.
- [x] 저장소: `references.rs`. 첨부는 앱 데이터에 보관(staged)했다가 목표를 보내면 `work-references/<날짜>_<목표ID 6자>/`로 옮긴다. 이름은 영문·숫자만(대소문자 충돌 없음), 자료 번호 R1…. 20,000자 넘는 글은 규칙으로 절 나누기(제목 → 문단, 절당 약 8,000자, 1,000자 미만은 합침, 코드·표·문장 중간은 자르지 않음, 이어 붙이면 원문과 같음). 루트·목표 인덱스(`INDEX.md`, `index.json`)는 기록에서 다시 만드는 사본이고, 사라진 파일은 `missing`. Git은 `.git/info/exclude`에만 추가. 백업 삭제 때 폴더 삭제, 새 버전이 물려받았으면 기록만 옮김. 보내지 않은 첨부는 7일 뒤 정리.
- [x] 자료 정리 담당: 새 역할(`reference curation`, Curator)을 새 팀에 넣고 기존 팀에는 한 번만 추가. 첨부 즉시 백그라운드로 제목 없는 20,000자 초과 글과 이미지만 정리안(JSON: 제목, 요약, 태그, 문단 번호로 절 경계, 관계)을 받는다. 앱이 모든 문단을 순서대로 한 번씩 덮는지, 크기 한도, 알려진 자료만 가리키는지 확인한 뒤에만 적용하고, 아니면 규칙 결과를 쓴다. 담당·연결이 없거나 이미지를 볼 수 없으면 이유를 칩에 보인다. 호출 토큰은 목표 없이 기록한다.
- [x] 엔진: CTO·PM에게 원문 대신 목표 인덱스를 준다. CTO는 요약 없는 자료에 `자료 요약 R1: …` 줄을 남기고 앱이 인덱스에 넣는다(추가 호출 없음). PM 근거 자료의 참조 경로는 이 목표(또는 물려받은 버전)의 실제 자료·절 파일만 허용, `work-references/`를 바꿀 파일로 적으면 형식 오류. 팀원 요청문에 근거 자료마다 인덱스 한 줄과 "지정된 자료만 열라"를 붙인다. 이미지가 근거인 업무는 이미지를 볼 수 있는 연결(Claude CLI 또는 `images` 표시)의 팀원에게만 배정. 폴더 프로젝트 복사본은 `work-references/`를 빼고 지정 자료만 넣는다. 백엔드 프로토콜 37.
- [x] 화면(v3 새 목표 입력): 4,000자 넘는 붙여넣기는 칩으로(되돌리기 가능), md·txt·이미지 첨부·끌어놓기, 이미지는 화면에서 긴 변 1,568px·28px 조각 1,568개 이하(세밀하게: 2,576px·4,784개)로 줄여 WebP(화면 캡처 0.95, 사진 0.85)로 다시 저장해 메타데이터를 지움. 칩에서 설명 입력·빼기·정리 상태. 목표 대화 머리글 `참조 자료 N`에서 자료·절·쓰는 업무 확인.
- [x] 검증: `cargo test --lib` 142(기준선 126 + 근거 복사 Git 1 + references 10 + curation 2 + 배정 1 + 참조 근거 검증 1 + 폴더 복사 1), `cargo check --all-targets`, clippy 새 파일 경고 없음, 세 프런트 `tsc`·빌드, `vitest` 96(기준선 92 + 4). 모의 앱(헤드리스 Chromium)에서 긴 붙여넣기 → 칩, md·PNG 첨부, 3000×1800 PNG가 1389×833 WebP(조각 1,500개)로 변환되고 백엔드 헤더 해석과 일치, 목표 보내기에 자료 ID 전달, 참조 자료 목록 확인, 콘솔 오류 0.
- 남은 위험: Codex CLI의 이미지 읽기는 미확인이라 기본으로 이미지 업무를 받지 않는다. 실제 정리안 품질, 토큰 절감 수치, WebView2의 WebP 변환은 QA-47로 확인한다. v1/v2와 대화 메시지 첨부는 범위 밖.
