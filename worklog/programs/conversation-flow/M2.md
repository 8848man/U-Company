# M2 — 홈과 자동 시작 (완료, 모의 렌더링 검증)


- [x] 변경: v3 홈을 왼쪽 목표 목록(`V3ChatHome`: 결정이 필요한 목표 먼저, "결정 필요" 표시, `+ 새 목표`) + 가운데 대화로 바꿨다. 실행 목표는 어느 화면에서 열어도 홈의 대화로 열리고(`openGoalWorkspace`가 홈으로 전환), 회의 목표는 기존 회의 패널을 쓴다. 목표를 고르지 않으면 가운데에 기존 새 목표 입력(준비 안내, 결정할 일 포함, 목표 카드 목록은 숨김)이 보인다. 새 목표를 보내면 만든 직후 실행 막힘이 없을 때 바로 `run_goal`을 부른다. 막혀 있으면 대화의 `지금 할 일` 카드가 이유와 연결·팀 설정 버튼을 보인다. 대화 안의 설정 이동 버튼은 선택한 목표를 유지한다.
- [x] 검증: 세 프런트 `tsc`, `vitest` 79, 세 빌드 통과. 모의 렌더링(1280px, 800px)으로 목표 목록과 대화 배치를 확인했고, 대화 머리글의 Office 버튼이 제목 아래로 내려가던 것을 고쳤다.
- 남은 위험: 실제 앱의 전체 셸 안 높이(머리글 70px 가정)와 스크롤은 Windows에서 확인 필요(QA-45). 엔진은 바뀌지 않았다.
