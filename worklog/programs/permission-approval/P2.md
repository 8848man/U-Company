# P2 — 결과 전달과 목표 대화 QA 맥락 (완료, 오프라인 검증)

- [x] 팀원 요청문: 의존하는 완료 업무와 같은 재작업 회차의 앞선 완료 업무 결과(업무당 1,500자, 합계 6,000자), 재작업이면 최근 QA가 실패한 기준과 근거를 붙인다(`goal_context::earlier_results`). PostGen에서 측정값이 README 업무에 전달되지 않던 경우다.
- [x] QA 요청문: 최신 재작업 회차 업무가 보고한 내용(업무당 800자)을 "파일에서 확인할 것"으로 붙인다(`repair_reports`).
- [x] 목표 대화(질문·메시지): 최근 산출물별 QA 판정, 실패 기준과 근거, 재작업 사용·한도, 멈춤 종류·사유(`review_digest`). AI 호출 없음.
- [x] 명세: DM-03, GC-01.
- [x] 검증: `cargo test --locked --lib` 163 통과·3 무시(+2).
