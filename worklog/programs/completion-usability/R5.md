- [x] R5: `goal_result.rs` — 완료 업무의 파일 목록(존재 여부)과 실행·시험 방법, 멈춤 기록(`goal_block`: 엔진 멈춤과 재시작 중단 모두) 종류별 통계, 프로젝트 폴더 열기. 명령 3개(프로토콜 39). v3 결과 칸 맨 위 요약과 `폴더 열기`, 설정 › 프로젝트의 "목표가 멈춘 이유" 카드.
- [x] 검증(두 라운드 공통): `cargo test --locked --lib` 158 통과·2 무시(+2 결과·통계 규칙; 종단 시험에 결과 요약 5파일·`index.html`·`node --test` 안내, 거절 시 `needs_scope` 통계 1건 단언 추가), `vitest` 116(+4 어림), 세 프런트 `tsc`.
