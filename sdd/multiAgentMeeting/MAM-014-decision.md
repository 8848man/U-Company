사용자 원문: "셋 다 채택으로 가자" (2026-10-09). MAM-013 §5의 권고안을 그대로 채택한다.

| ID | 질문 | 결정 |
| --- | --- | --- |
| D1 | 패킷을 명령줄 인자가 아니라 표준 입력으로 보내는가. 실행 목표의 호출 방식도 함께 바뀐다 | **채택**. 공급자 하네스와 Windows 실제 CLI로 확인되기 전에는 기존 인자 방식을 유지하고, 확인된 공급자만 표준 입력으로 전환한다 |

## 이 결정이 바꾸는 것과 바꾸지 않는 것

- 바꾸는 것: ME-02의 "자료·연결이 바뀌면 차단" 규칙(D3, MAM-013 P5), 응답 형식 오류 시 즉시 차단 규칙(D2, P3), 공급자 호출 전달 방식(D1, P1, AI-03).
- 바꾸지 않는 것: 내용을 앱이 자르거나 고쳐 쓰지 않는다. 결과 불명 호출은 자동 재전송하지 않는다. 계획에 없는 팀원·자료·호출은 막는다. Claude/Codex CLI 읽기 전용 경계(MAM-010 D3)와 계획 단위 승인(MAM-010 D4)은 그대로다.
- 이 결정은 구현 지시의 근거일 뿐 프로젝트 파일 쓰기·외부 전송·배포 승인이 아니다([Security](../security.md)).

구현 범위와 순서는 [MAM-015](MAM-015-revision.md)가 정한다.
