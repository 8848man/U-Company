# ADR-0069 — Retire the v1 and v2 frontends; v4 is the default app

Status: Accepted (2026-11-10, CEO). Owners: [Architecture](../../architecture.md), [Implementation map](../../implementation-map.md), [Validation](../../validation.md). Supersedes the frontend-coexistence parts of [ADR-0033](ADR-0033.md) and [ADR-0039](ADR-0039.md).

Date: 2026-11-10

## Context

Four frontends shared one Tauri engine: v1 (`src/App.tsx`, the default `npm run tauri dev`), v2 (`v2/`), v3 (`v3/`) and v4 (`v4/`, which renders the v3 controller with preset slots). New behaviour since ADR-0046 targeted v3/v4 only, so v1 and v2 kept older flows (for example the old conversation screen that sent follow-up work to a "new goal" instead of the same conversation, Self grill U17). Manual QA had already moved to v4 ([WLG-073](../../../worklog/milestones/WLG-073.md)). Keeping two copies of the controller (v2 `App.tsx` and v3 `App.tsx`) was recorded migration debt.

## Decision

1. Remove the v1 and v2 app entries: root `index.html`, `src/App.tsx`, `src/main.tsx`, `src/GoalConversationChat.tsx` (used only by v1/v2), and `v2/` (`App.tsx`, `main.tsx`, `V2Home.tsx`, launchers, Vite/TypeScript config, README).
2. Keep the v2 parts the v3 controller renders and move them to `src/shell/` unchanged: `V2Navigation`, `V2Work`, `V2Connections`, `V2Projects`, `V2NotificationSettings`, `v2.css`. Their names stay so history and tests remain searchable.
3. v4 is the default app. `src-tauri/tauri.conf.json` serves `v4/dist`; `npm run dev`/`build` build v4; `scripts/start-windows.ps1` forwards to `v4/start-windows.ps1`; `v4/start-ubuntu.sh` is added. The v3 entry stays as a preset-free variant of the same controller.
4. The Windows installer build moves to `scripts/build-installer-windows.ps1` with `src-tauri/tauri.installer.conf.json`, which only turns on the NSIS bundle for the default (v4) app. The Claude connection diagnostic moves to `scripts/`.
5. The engine, its commands and the saved data are unchanged. Data written by v1/v2 stays readable by v3/v4 because they always shared the same store.

## Consequences

- The controller duplication is gone: `v3/src/App.tsx` is the only controller, so the planned shared-hook extraction is no longer needed.
- Self grill U17 is resolved by removal: the only conversation screen is `GoalChat`, which follows [UF-03](../../userFlow/UF-03-goal.md).
- Past ADRs, worklog rounds and QA results that mention v1/v2 remain historical records.
- QA items written for v2 (QA-36~38) run in v4 ([qa/MANUAL-QA.md](../../../qa/MANUAL-QA.md)).
