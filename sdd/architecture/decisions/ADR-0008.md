# ADR-0008 — Allow a single implementation task for one artifact

Status: Accepted (2026-10-01)

The original planner required two file-changing tasks for every goal to demonstrate parallel execution. This prevents a CEO goal requesting exactly one standalone HTML file: distinct task ownership would require an unwanted second file or conflicting edits. The planner now accepts one to twelve file-changing tasks and schedules parallel work only when more than one independent task exists. The two-task fixture remains a separate concurrency acceptance test. Approval, isolated worktree, integration, and QA still apply to a single task.
