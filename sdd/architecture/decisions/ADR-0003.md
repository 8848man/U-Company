# ADR-0003 — Isolate parallel writing tasks with Git worktrees

Status: Accepted

Date: 2026-10-01

Affects: [Architecture](../../architecture.md), [Domain](../../domain/00_index.md)

Context: Several agents may work on one project while the app can crash or be restarted.

Decision: Give each parallel writing task its own Git worktree; persist state and events before execution and serialize integration.

Alternatives: A shared checkout invites overlapping writes; copying folders loses Git lineage and makes integration harder.

Consequences: Writing workflows require a Git project and worktree cleanup must account for interrupted sessions.
