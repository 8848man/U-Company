# ADR-0040 — Office character sprites from a CC0 pack, as an optional visual skin

Status: Accepted (2026-10-10). Refines the asset part of [ADR-0004](ADR-0004.md) ("Reuse only Pixel Agents Canvas visualization"), which required auditing sprite rights and using original art until they were verified.

## Context

The CEO asked to use the Pixel Agents character look. Pixel Agents' README credits its six characters to JIK-A-4's *Metro City* free top-down character pack. On 2026-10-10 the pack's itch.io page listed its asset license as Creative Commons Zero v1.0 Universal; the author states it may be used as wished, including commercially, and that credit is appreciated but not required. Pixel Agents' code is MIT; its README does not state separate terms for its bundled furniture, floors and walls.

## Decision

- Use the **original CC0 Metro City pack** for characters, not Pixel Agents' modified copies, so the asset rights come from one clearly licensed source. Furniture, floors and walls from Pixel Agents are not used until their rights are recorded.
- Sprites are an **optional skin**: PNG sheets plus a `manifest.json` (frame size, idle frame, working frames, source, license) in `src/office/assets/characters/`. A missing or invalid manifest falls back to the built-in pixel characters; the app never guesses a sheet layout.
- Every visible state still comes from saved engine state ([progress visibility policy](../../progress-visibility.md)): the working cycle plays only for a teammate the engine reports as working, and reduced-motion settings show a still frame.
- Record the source and license in `third_party/` before committing the sheets; credit JIK-A-4 even though CC0 does not require it.
- **Applied 2026-10-11 (revised the same day at the CEO's request):** the downloaded pack is layered (body per skin tone, outfits/suits, hair, beard). The app bundles the raw pack from `assets/characters/` unchanged and composes each character **at runtime** on a canvas (`src/office/metrocity.ts`: shadow → body → outfit → beard → hair; hat costumes hide hair), cached per look. No bake script or generated sheet is kept. Each teammate may store an optional `appearance` (skin, outfit, hair, beard) chosen in Office › 개인 설정 › 캐릭터 모습; the backend accepts only catalog choices. Without a saved look, the five seeded teammates use fixed defaults and anyone else, including external staff, gets a stable pick derived from their id. A character file may carry an `appearance`; an unknown one is dropped and shown as ignored. If the pack is missing, Office keeps the built-in pixel figures.

## Alternatives and consequences

Copying Pixel Agents' modified sprites would also be plausible under its MIT license, but would mix two provenance chains. Drawing new art keeps full control but delays the requested look. The chosen path needs the CEO to download the pack from itch.io once (the page requires an interactive download) and one manifest written after inspecting the real sheet layout.
