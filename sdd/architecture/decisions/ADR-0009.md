# ADR-0009 — Persist operational progress, not model reasoning

Status: Accepted (2026-10-01)

The Office originally showed only coarse task status while CLI stdout was buffered until exit. The UI now derives active characters from the persisted goal/task state and displays bounded runtime milestones as events linked to an agent and goal/task. Structured CLI events are reduced to tool or stage summaries before storage; raw prompts, reasoning, command arguments, and stdout are not copied to the UI. Idle character dialogue is explicitly illustrative. This keeps the experience understandable without claiming access to private model reasoning and lets the same progress survive a UI reload.

The alternative of rendering raw CLI JSON was rejected because it is noisy and may contain private instructions, credentials, or project content. The alternative of simulated active logs was rejected because it would misstate actual progress.
