# ADR-0004 — Reuse only Pixel Agents Canvas visualization

Status: Accepted

Date: 2026-10-01

Affects: [Architecture](../../architecture.md), [Product](../../product.md)

Context: Pixel Agents provides a relevant office visualization; this product's core is an organization workflow.

Decision: Reuse the necessary MIT-licensed Canvas UI code after source and asset review, while owning state and orchestration independently.

Alternatives: A full fork couples the engine to Pixel Agents' current runtime assumptions; a new Canvas has more initial UI work.

Consequences: Retain license notice and audit sprite/font rights separately. Use original or placeholder art if rights cannot be verified.
