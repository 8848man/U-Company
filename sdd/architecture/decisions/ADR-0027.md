# ADR-0027 — Verified selective continuation of revised goals

Status: Accepted

Date: 2026-10-08

Affects: [Goal conversation](../../goalConversation/00_index.md), [Domain](../../domain/00_index.md), [Security](../../security.md)

## Context

A CEO can direct a team member in the goal conversation, but the current linked revision always restarts CTO analysis, PM planning, and all implementation work. Some prior tasks may already be integrated. A model can judge semantic impact but cannot establish from prose that a file is unchanged or an approval still applies.

## Decision

Keep immutable linked goal revisions and safe checkpoints. Preserve the addressed team member as routing provenance, then invoke that connected member for a read-only escalation memo when the linked revision starts. CTO analyzes impact and PM supplies a delta plan with explicit old task IDs proposed for reuse. Capture per-file digests at task integration; the engine accepts reuse only for completed source tasks whose recorded files and dependency chain still match the selected project and do not overlap new task ownership. Save the continuation decision and show it in the conversation. Perform independent QA for the revised goal. New writes receive new approval; old approvals are historical.

## Alternatives

- Trust the addressed worker's answer to pick the resume point: model text cannot prove current file state or approve a write.
- Rerun every task for every revision: wastes completed work and can overwrite valid artifacts.
- Reuse a previous write approval for a new goal: silently extends authorization across an intent change.

## Consequences

Older tasks without integration digests cannot be automatically skipped. An unintegrated worktree remains inspectable but is not completion evidence. A no-write revision can go directly to independent QA. The engine must recheck reused file digests before QA and block on drift. The UI must distinguish a team-routing record, model recommendation, and engine-verified continuation.
