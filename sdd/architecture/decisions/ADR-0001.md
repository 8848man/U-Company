# ADR-0001 — Use Tauri 2, Rust, and SQLite

Status: Accepted

Date: 2026-10-01

Affects: [Architecture](../../architecture.md), [Product](../../product.md)

Context: The product needs a local desktop UI, process control, persistence, and Windows plus Ubuntu support.

Decision: Use Tauri 2 with a Rust orchestration core, React UI, SQLite persistence, and a narrow OS service boundary.

Alternatives: Electron simplifies Node CLI integration but ships a larger browser runtime; a localhost web app has weaker desktop integration.

Consequences: Rust handles process and state safety; Linux needs WebKitGTK development dependencies and real platform testing.
