# ADR-0013 — Reversible teammate hiding and display-only goal groups

Status: Accepted (2026-10-02)

Hard deletion of an agent would leave task, event, and token records with a missing assignee. Hiding an agent by setting `enabled=false` preserves those references and allows restoration. The backend rejects disabling an implementation agent while it owns unfinished tasks. Existing work remains reviewable. This also avoids reseeding default agents after the last agent is deleted.

A work-group label on a goal is presentation metadata. Goals sharing a label are shown together on the board, while their task graph, approvals, QA limit, and execution remain separate. Merging goals or introducing a shared execution entity would change approval scope and scheduler behavior; that requires a separate design. An explicit label is preferable to grouping by project or similar text, which could imply a relationship that the CEO did not establish.
