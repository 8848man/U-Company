# Goal conversation topic index

목표에 묶인 CEO 대화, 지침 전달, 화면, 중단 복구와 열린 작업 진입점을 연결한다. [도메인 상태](../domain/00_index.md)와 [보안 승인](../security.md)은 이 주제의 상위 불변식이다. 각 규칙의 원본은 아래 파일 하나에만 있다.

| ID | 원본 | 소유하는 사실 |
| --- | --- | --- |
| GC-01 | [대화 턴과 답변](GC-01-turns.md) | 목표별 턴, 실제 AI 정체성, 질문·답변, 대화체 정책 |
| GC-02 | [지침과 체크포인트](GC-02-guidance.md) | 방향 변경의 전달·검증·새 목표 버전·재사용 경계 |
| GC-03 | [공통 목표 작업공간](GC-03-workspace.md) | 한 화면의 정보 계층, 입력, 대화와 진행 표시 |
| GC-04 | [중단 목표 복구](GC-04-recovery.md) | 저장 상태에 따른 재시도·승인·새 버전 선택 |
| GC-05 | [열린 작업 진입점](GC-05-open-work.md) | 전역 작업 목록, 업무 담당자 대화로 이동 |

관계 어휘는 `produces`(상태·턴을 만듦), `routes_to`(사용자 행동이 해당 개념으로 이어짐), `reads`(저장된 사실을 표시), `constrains`(대상 규칙에 의해 제한됨)이다. 이 링크는 실행 권한이 아니다. GC-03에서 대화에 들어가면 GC-01이 턴을 저장하고, 방향 변경이면 GC-02가 체크포인트를 소유한다. 실패한 목표는 GC-04가 판단하며 GC-05는 어느 탭에서든 같은 목표 작업공간으로 들어오는 길이다.

[수용 기준](acceptance.md)은 이 다섯 원본을 함께 검사한다. 실제 구현·데스크톱 검증은 [WORKLOG](../../WORKLOG.md)와 [수동 QA](../../qa/MANUAL-QA.md)를 따른다. [사용자 여정](../userFlow/UF-04-conversation.md)은 CEO가 보는 순서만 소유한다.
