# UF-02 — AI 팀 준비

## 목적과 시작 조건

CEO가 실제로 사용 가능한 AI 연결을 확인하고 팀원의 역할·지침·AI를 배치한다. 프로젝트 선택 전에도 연결은 설정할 수 있으나 목표 실행 전에는 필요한 역할의 연결 상태를 확인한다.

## 사용자 흐름

1. v2의 설정 > AI 연결에서 등록된 AI 상태를 먼저 확인한다. `AI 추가`를 열면 자동 발견 결과의 **실제 설치 경로·상태**와 설치되지 않은 지원 도구를 구분할 수 있다. 필요하면 사용자 지정 CLI, API 또는 어댑터를 명시적으로 추가한다.
2. 로그인 필요 또는 상태 확인 실패가 보이면 해당 공급자의 고정된 복구 행동을 선택하고, 로그인 완료 후 같은 저장 경로를 다시 검사한다. 창을 열었다는 사실만으로 연결 성공으로 표시하지 않는다.
3. v2의 설정 > 팀에서 여러 팀원의 AI를 일괄 배정하거나 숨긴 팀원을 복원한다. Office 캐릭터를 클릭하면 그 구성원의 역할·지침·모델과 활동만 조정한다. 새 구성원에는 역할 지침 Preset을 사용할 수 있다.
4. 목표를 시작하기 전에 CTO·PM·개발·QA 등 실제 필요한 역할이 활성화되고 적합한 런타임에 연결됐는지 확인한다.

## 종료와 분기

사용 가능한 연결과 팀 배치가 저장되면 목표 실행으로 간다. 모델은 발견됐지만 파일 작업 능력이 없거나 인증이 안 된 경우 해당 역할의 실행은 막히며 이유와 다음 설정 행동을 보여준다. 진행 중 연결 실패는 중단 복구로 이어진다.
