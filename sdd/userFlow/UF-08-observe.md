# UF-08 — 진행·리소스 관찰

## 목적과 시작 조건

CEO가 목표가 **어디까지 진행됐고 누가 담당하며 어떤 근거와 토큰을 사용했는지** 확인한다. 선택 프로젝트와 저장된 목표·업무가 있을 때 내용이 채워진다.

## 사용자 흐름

1. CEO 데스크, Office의 목표 레일, 업무 현황 또는 열린 작업에서 현재 목표를 고른다. 이들은 동일한 저장된 목표 작업공간으로 연결된다.
2. 첫 화면에서 상태·담당·다음 행동과 필요한 결정을 본다. 진행 정보를 펼쳐 업무별 담당자·단계, 최근 실제 활동, QA 근거, 토큰 기록의 추정/보고 여부를 확인한다. Office 캐릭터의 활동 표시도 저장된 이벤트를 반영한다.
3. 토큰 메뉴에서 선택 프로젝트 총량을 기준으로 목표·팀원·모델별 사용량과 비율을 살핀다. 정렬과 설명은 로컬 기록을 사용하며 새 AI 호출을 만들지 않는다.
4. 더 긴 목록이나 문서는 펼쳐 원문을 확인하고, 중단이나 승인 필요가 보이면 해당 목표 대화의 행동으로 이동한다.

## 종료와 분기

관찰 자체는 작업을 시작하거나 승인하지 않는다. 추정 토큰은 청구 금액이나 공급자 한도로 표시하지 않는다. 저장되지 않은 AI의 사적 사고 과정은 보여주지 않고, 실제 런타임·엔진 이벤트만 진행 근거로 사용한다.
