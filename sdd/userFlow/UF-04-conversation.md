# UF-04 — 목표 대화와 방향 변경

## 목적과 시작 조건

CEO가 목표에 묶인 팀원과 대화해 이해·진행·이슈를 확인하거나 자연어 지침으로 방향을 바꾼다. CEO 카드, Office, 업무 현황 또는 열린 작업 버튼에서 같은 목표 대화를 연다.

## 사용자 흐름

1. 대화 상단에서 목표·현재 단계·담당자·다음 행동을 확인하고 말을 걸 팀원을 선택한다. 실제 연결·모델과 이전 대화의 상태가 표시된다.
2. 한 입력창에서 질문이나 지시를 보낸다. 연결된 AI가 메시지 의도를 읽기 전용 호출로 분류한다. 질문은 답변을 저장하고, 모호하면 확인 질문을 돌려준다.
3. 명확한 방향 변경은 CEO의 원문을 지침으로 기록하고 안전한 체크포인트를 기다린다. 기존 호출을 즉시 바꿨다고 표시하지 않는다.
4. 체크포인트 이후 연결된 새 목표 버전에서 담당 팀원 인계, CTO 영향 분석, PM 남은 작업 계획을 수행한다. 엔진은 완료 작업의 재사용 근거를 검증한다. 새 파일 작업만 새로운 승인으로 간다.

## 종료와 분기

질문은 원래 목표를 바꾸지 않고 끝난다. 지침은 새 목표 버전으로 이어지고, 이전 목표와 산출물 이력은 남는다. 승인 요청은 대화 응답만으로 통과하지 않는다. 팀원이 불가하거나 자동 재계획이 실패하면 저장된 이유를 바탕으로 복구한다. 완료 목표에 새 실행을 요청하면 후속 목표가 필요하다는 안내를 받는다.
