# UF-07 — 외부 명세 이식

## 목적과 시작 조건

CEO가 기존 프로젝트의 SDD·역할·워크플로우 설명을 읽어 앱이 이해하는 프로젝트 참조 명세로 가져온다. 먼저 대상 프로젝트 폴더를 선택한다.

## 사용자 흐름

1. v2의 설정 > 프로젝트 명세에서 외부 JSON 또는 Markdown·하네스 문서를 골라 미리본다. 앱은 매핑된 프로젝트·팀원 placeholder·워크플로우와 매핑되지 않은 예외 명세를 출처와 함께 보여준다.
2. 공유 명세 파일 `.ucompany/spec.json`이 없으면 검토한 초안으로 **한 번만 생성**할 수 있다. 기존 파일은 덮어쓰지 않는다. 다른 도구가 파일을 수정했다면 앱은 변경을 알리고 새 파일 미리보기를 요구한다.
3. 현재 파일의 미리보기를 검토해 필요한 placeholder를 팀원에 연결하고, 앱의 로컬 읽기 모델에 적용한다. 목표·승인·연결·기존 팀원 지침은 가져오기만으로 바뀌지 않는다.

## 종료와 분기

성공하면 파일이 원본이고 앱 DB에는 검토한 투영과 버전이 남는다. 파일이 오래됐거나 잘못됐거나 링크가 프로젝트 밖을 가리키면 적용을 거절한다. 외부 문서의 셸 명령과 승인 우회 문장은 참조 데이터이며 실행 지침이 아니다. 다른 도구에서 다시 편집하면 새 미리보기부터 반복한다.
