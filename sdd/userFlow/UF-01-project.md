# UF-01 — 프로젝트 선택

## 목적과 시작 조건

CEO가 작업할 **로컬 폴더 자체**를 프로젝트로 등록하거나 기존 등록 항목으로 전환한다. 앱 실행 후 프로젝트가 없거나 다른 프로젝트로 바꾸려는 상태에서 시작한다.

## 사용자 흐름

1. v2에서 CEO가 전역 프로젝트 선택기를 열어 등록된 폴더를 전환하거나 `폴더 추가`로 설정 > 프로젝트에 간다. OS 폴더 선택기에서 빈 폴더, 파일이 있는 폴더, 하위 폴더가 있는 폴더 중 하나를 고른다.
2. 앱은 선택한 폴더를 읽고 이름·읽기 쉬운 경로·실행 모드를 표시한다. 등록 자체는 폴더를 수정하지 않는다.
3. 기존에 등록한 동일 폴더라면 저장된 프로젝트 ID·목표·QA 기본값을 유지하면서 실행 모드를 다시 확인한다. 다른 프로젝트를 선택해도 기존 목표의 프로젝트 소속은 바뀌지 않는다.

## 종료와 분기

성공하면 선택 프로젝트가 뒤이은 목표와 명세 이식의 범위가 된다. 선택을 취소하면 아무 프로젝트도 새로 등록하지 않는다. 폴더를 열 수 없으면 경로 문제를 보여주고 선택 단계에 머문다. Git이 없는 폴더도 유효하다. Git 초기화가 필요한 **중단 목표**는 별도 승인·복구 흐름으로 간다.
