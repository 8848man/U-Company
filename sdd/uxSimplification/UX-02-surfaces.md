# UX-02 — 화면별 정보 우선순위

## 공통 표시 규칙 제안

각 기본 화면은 **무엇을 할 수 있는가** 한 문장, 현재 상태 한 줄, 주 행동 하나를 우선한다. 긴 설명과 기술 세부는 선택한 **목표·프로젝트·AI 연결·팀원**의 상세로 이동한다. 한 정보의 편집 위치는 하나만 둔다. 다른 화면에는 짧은 요약과 원본 상세로 가는 링크만 남긴다. 승인 범위·거절 이유·복구 행동은 이 규칙의 예외로 즉시 보여야 한다. 기존 [다섯 항목/긴 콘텐츠 정책](../content-density.md)은 목록과 텍스트 안에서 계속 적용한다.

| 화면 | 첫 화면에 남길 정보와 주 행동 | 상세 또는 설정으로 옮길 정보 | 현재 중복을 없애는 방법 |
| --- | --- | --- | --- |
| 홈(CEO 데스크) | 선택 프로젝트 이름, **지금 결정할 일**, 목표 입력(드롭다운으로 `목표 수행`/`회의` 모드, 기본 `목표 수행`; 모드에 따라 버튼과 첫 전송 안내가 바뀜), 진행 목표의 짧은 상태·담당·다음 행동. 주 행동은 상태에 따라 목표 전달 또는 유효한 결정 열기 | 프로젝트 경로·방식·QA 기본값, 누적 토큰, 목표별 QA 설정·보고 원문은 해당 상세 | 영구 히어로와 온보딩 단계를 첫 사용 이후 접고, 목표 카드의 여러 버튼을 `목표 열기`와 실제 필요한 행동으로 줄인다 |
| 업무 현황 | 목표별 단계·담당·막힌 점을 비교하는 목록/그래프와 목표 선택 | 업무별 긴 지침·파일·worktree 경로·결과·전체 이벤트는 선택 목표의 `진행 정보` | 승인 카드·업무 카드·활동 기록을 전 목표 대상으로 한꺼번에 나열하지 않는다. 유효한 승인 알림은 홈/목표 작업공간의 같은 요청으로 연결한다 |
| Office | 방/캐릭터, 현재 진행 목표의 **간결한** 선택 줄, 선택 팀원의 실제 활동. 주 행동은 목표 또는 팀원 선택 | 팀 전체 일괄 AI 배정·숨김/복원은 설정 > 팀. 개인 역할 설정은 캐릭터 선택 후 명시적 `개인 설정` | 목표별 긴 그래프와 업무 기록은 공통 목표 작업공간으로 보낸다. 미선택 시 개인 패널의 빈 설명을 최소화한다 |
| 토큰 | 현재 프로젝트 총량, 목표별 비교 그래프, 정렬. 목표 선택 시 상세 확장 | 팀원·모델의 세부 호출 기록은 선택 목표/팀원의 확장. 인사이트는 그래프 **끝**에 한 가지 핵심 제안부터 표시 | 홈·Office의 수치는 짧은 요약만 남기고 전체 분석은 토큰 메뉴가 소유한다. 보고/추정 구분은 상세와 요약 모두 유지 |
| 설정 > 프로젝트 | 등록된 폴더의 이름·선택 상태, `폴더 추가`; 선택 프로젝트 상세 진입 | 경로·Git 방식·새 목표 QA 기본값·공통 SDD 파일/가져오기/예외 명세는 프로젝트 상세의 각각 이름 붙은 섹션 | 현재 프로젝트 메뉴 아래에 늘어선 전체 SDD 이식 폼을 기본 목록에서 제거한다. 등록 자체는 파일을 바꾸지 않는다 |
| 설정 > AI 연결 | **등록된 AI의 상태와 필요한 조치**를 먼저 표시. 주 행동은 연결 상태 확인 또는 AI 추가 | 발견 목록은 `AI 추가` 진입 후, 미설치 Preset은 지원 목록, CLI 경로·모델 ID·로그인 진단은 해당 연결 상세 | 현재 발견·미설치·직접 추가·등록 네 블록을 동시에 읽게 하지 않는다. 실제 설치 여부와 저장된 연결은 계속 구분한다 |
| 설정 > 팀 | 팀 명단, 연결 부족/숨긴 팀원 수, 일괄 배정 진입 | 구성원별 역할·지침·모델은 Office 개인 설정. 이식 placeholder의 매핑은 프로젝트 명세 상세에서 연결 | Office 시각화와 조직 전체 설정을 분리한다. 진행 중 업무 때문에 숨길 수 없는 이유는 즉시 보여준다 |
| 설정 > 알림 | 시스템 알림·앱 소리의 독립 스위치와 샘플 시험 | 실제 승인 범위·중단 이유는 목표 작업공간에서 확인 | [알림 정책](../notifications.md)에 따라 새 승인·중단만 신호로 보낸다. 기존 대기 항목은 재시작 때 재생하지 않는다 |
| 공통 목표 대화 | 제목·상태·담당·**지금 필요한 결정**과 최근 대화, 입력창 | 업무·QA·토큰·과거 이력은 `진행 정보`; 이전 버전 인계·Git 복구 등은 상태가 맞을 때만 한 맥락 카드 | 현재 대화 상단의 여러 정보 카드가 동시에 나타나지 않도록 상태별 우선순위를 둔다. 권한이 필요한 결정은 단순 대화로 처리하지 않는다 |
| 회의 Goal 작업공간 | 같은 목표 작업공간에 현재 단계·발언 중인 팀원과 **계획 승인 > 단계 패킷 승인 > 복구 > 결정 자료** 중 한 카드 | packet 원문·전송 기록·전체 발언·추적 그래프·사용량은 해당 목표의 진행 정보; 자유 입력창 없음 | 새 최상위 메뉴나 별도 회의실을 만들지 않고 홈 목표 입력칸의 `회의` 모드에서 시작한다. Office는 참여 캐릭터와 저장된 발언 요약만 보여 준다 |

## 같은 사실의 표시 소유자

| 사실 | 상세의 원본 화면 | 다른 화면에서 허용하는 요약 |
| --- | --- | --- |
| 목표 단계·다음 행동·승인/복구 | 공통 목표 작업공간 | 홈·업무·Office에 한 줄과 동일 목표 링크 |
| 파일별 작업·QA·최근 실제 이벤트 | 목표 작업공간의 진행 정보 | 업무·Office에 담당/상태의 짧은 신호 |
| 프로젝트 경로·실행 방식·QA 기본값·SDD | 설정 > 프로젝트 상세 | 전역 선택기와 홈에 이름/선택 상태만 |
| AI 경로·인증·모델 카탈로그 | 설정 > AI 연결 상세 | 팀원 선택에 연결 이름과 준비 상태만 |
| 일괄 팀 배정·숨김 | 설정 > 팀 | Office에는 개인 활동과 설정 진입만 |
| 프로젝트/목표 토큰 분석 | 토큰 | 홈·Office에는 근거 표시가 있는 한 줄 수치 |

이 표는 화면 소유권 제안이며 저장 모델을 바꾸지 않는다. 프로젝트 파일·승인·작업 결과·토큰 기록은 기존 원본에서 읽는다. 새 요약을 위해 추가 모델 호출을 하지 않는다.
