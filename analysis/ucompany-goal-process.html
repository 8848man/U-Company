하나의 목표가
팀의 결과가 되기까지

프로젝트와 AI 팀을 준비한 뒤 CEO의 목표를 분석·계획·승인·실행·검증합니다. 단계를 선택하면 누가 어떤 근거와 도구로 다음 단계로 넘기는지 볼 수 있습니다.

설명용 지도 · 실제 목표를 실행하지 않음파일 쓰기 · 외부 전송은 범위별 승인현재 계약과 v3 제안 구분

목표 실행 순서

번호 순으로 진행합니다. 카드를 클릭하거나 Tab으로 이동해 Enter / Space로 선택하세요.

다른 길도 있습니다

분기를 선택하면 돌아가는 지점과 승인 조건이 표시됩니다.

선택한 단계

외부 Skills 적용 방법론 제안

Skill은 역할별 일하는 방법을 담은 외부 지침 후보로 다룹니다. 가져온 텍스트가 엔진의 단계나 승인 규칙을 바꾸지는 않습니다.

01 · 준비·계획

후보 검토

출처, 라이선스, 버전, 목적, 입력 자료, 요구 도구와 위험 명령을 확인합니다. PM은 산출물·수용 기준과 맞는 후보만 계획에 제안합니다.

02 · CEO 승인

사용 범위 결정

어떤 역할이 어떤 자료·파일·명령·전송 대상에 Skill을 쓸지 승인 카드에서 확인합니다. 추가 파일이나 위험 명령은 별도 범위 판단을 거칩니다.

03 · 실행

역할·런타임 연결

기존 팀원에 역할 지침을 연결하고, 저장된 AI 연결과 실제 어댑터 능력을 검사합니다. 텍스트 모델만 있으면 파일 작업을 맡기지 않습니다.

04 · QA

결과·권한 검증

독립 QA가 산출물별 기준·근거와 선언 파일만 바뀌었는지 확인합니다. Skill의 설명이나 모델의 성공 선언은 완료 증거가 아닙니다.

현재 경계: 외부 SDD·역할 파일·하네스 지침을 검토해 프로젝트별 로컬 프로필에 저장하는 경로는 명세에 있습니다. 가져온 Skill을 실행 가능한 도구로 자동 등록하거나 현재 진행 중인 목표의 프롬프트에 자동 적용하는 기능은 별개이며, 여기서는 구현된 것으로 표시하지 않습니다.

무엇이 확인되었나요?

이 페이지는 실제 실행 상태를 읽지 않는 오프라인 설명 자료입니다.

현재 계약·구현 근거

선택 프로젝트에 목표를 묶고, CTO·PM·담당자·QA가 단계별로 참여합니다. 승인된 파일만 격리 작업 후 통합하며 저장된 근거로 완료를 판정합니다.

v3 제안·확장

고객 목표를 출시 준비 같은 비코드 업무까지 넓혀 산출물별 인수 묶음을 만드는 방향입니다. 외부 Skills 적용 방법론도 이 페이지의 제안입니다.

아직 확인 필요
